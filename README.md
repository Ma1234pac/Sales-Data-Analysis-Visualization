# 📊 MATLAB Sales Data Analysis

A small MATLAB project for analyzing and visualizing monthly sales data.

The project demonstrates basic data analysis, statistics, moving averages,
and data visualization using MATLAB.

## 🚀 Features

- Import data from CSV
- Calculate total sales
- Calculate average and median sales
- Calculate minimum and maximum sales
- Calculate standard deviation
- Identify best and worst performing months
- Calculate monthly sales growth
- Calculate 3-month moving average
- Generate sales visualizations
- Automatically save figures as PNG files

## 🛠 Technologies

- MATLAB
- CSV
- MATLAB Tables
- MATLAB Plotting

## ▶️ How to Run

1. Clone the repository.

2. Open MATLAB.

3. Navigate to the project directory.

4. Run:

```matlab
main
```

The program will automatically load the CSV dataset and perform
the analysis.

## 📊 Output

The program calculates:

* Total sales
* Average sales
* Median sales
* Minimum sales
* Maximum sales
* Standard deviation
* Best performing month
* Worst performing month
* Monthly growth

It also generates three visualizations:

### Sales Trend

Shows monthly sales together with a 3-month moving average.

### Monthly Sales

A bar chart showing sales for each month.

### Sales Growth

A bar chart showing month-to-month percentage growth.
